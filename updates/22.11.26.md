**Сайт:** просмотрен на разных размерах экрана; исправлено недоразумение с чёрными полями в мобильном превью — они были за пределами страницы. Оформление обновлено по мотивам starkow.dev: тёмная палитра, терминальные заголовки, карточки проектов и игровые блоки.


**Интеграции:** добавлена загрузка публичных репозиториев GitHub. Для гостевой книги подготовлены интерфейс, API для Vercel и схема Supabase с премодерацией; локальный предпросмотр работает без подключения базы. Spotify отложен, карточки донатов остаются заглушками.


**Игры:** переработаны BlockBlast и Wordle с собственной реализацией механик — без копирования исходного кода или графики референса. Добавлены режимы BlockBlast, перетаскивание и постановка фигур, очки, очистка линий, ежедневная задача и локальные рекорды. Для Wordle — ежедневный и бесконечный режимы, архив, разные длины слов, английский и русский языки, настройки, клавиатура и статистика.


**Даты:** задан формат `DD.MM.YY` для гостевой книги и игровых дат.


**Общий рейтинг BlockBlast:** подготовлены API, SQL-миграция Supabase и интерфейс рейтинга. В INTEGRATIONS.md описано подключение; уточнено, что ограничение частоты применяется ко всем запросам рейтинга.

Проверены синтаксис JavaScript, основные сценарии игр, браузерный интерфейс и адаптивность на узких экранах; для API выполнены тесты с имитацией ответов базы. Счёт рейтинга передаётся клиентом, поэтому это не античит-соревнование. Словари Wordle ограничены отобранными словами.
